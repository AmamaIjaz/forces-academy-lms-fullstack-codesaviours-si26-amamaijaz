## 📊 Result Management

The LMS provides a complete subject-wise result system.

Each subject is displayed in a single row with the following marks distribution:

| Component | Marks |
|---|---:|
| Mids | 25 |
| Assignment | 15 |
| Quiz | 10 |
| Sessional | 10 |
| Final | 40 |
| **Total** | **100** |

Students can view their results and generate a print-friendly result sheet.

## 💰 Fee Management

The fee management system allows administrators to:

- Add student fee records
- Set fee amount
- Set due date
- Add fee description
- Mark fees as paid
- Mark fees as pending
- Track overdue fees

Students can view:

- Fee amount
- Due date
- Paid date
- Description
- Current status
- Total pending amount

---

## 📅 Timetable Management

Administrators can create timetable entries using:

- Class
- Day
- Time slot
- Subject
- Teacher

Students can view their timetable according to their registered class in a weekly timetable layout.

---

## 🔐 Authentication & Security

The project uses separate authentication systems for students and administrators.

### Student Authentication

Students log in using their registered email and password.

Passwords are securely stored using PHP password hashing.

### Admin Authentication

Administrators have a separate login system with an independent admin session.

Protected pages verify the appropriate session before allowing access.

### Database Security

Database operations use:

- MySQL prepared statements
- Parameter binding
- Password hashing
- Session-based authentication
